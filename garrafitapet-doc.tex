\section{Introduction}

The \texttt{garrafitapet} package provides
a miniature TikZ illustration of the Klein bottle.

Its purpose is to make it easy to insert a
representation of this fascinating mathematical
object into LaTeX documents.

\section{Requirements}

The package requires TikZ/PGF.

TikZ is loaded automatically by the package.

\section{Installation}

Place the file \texttt{garrafitapet.sty}
in the same directory as your main LaTeX document.

Load the package in the preamble:

\begin{verbatim}
\usepackage{garrafitapet}
\end{verbatim}

\section{Usage}

To insert the Klein bottle, simply write:

\begin{verbatim}
\garrafaklein
\end{verbatim}
